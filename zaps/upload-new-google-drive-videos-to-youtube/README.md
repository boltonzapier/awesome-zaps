# Upload new Google Drive videos to YouTube with titles and descriptions

Each new video file added to Google Drive is uploaded to YouTube, titled after the file and described from its Drive notes, so finished videos reach your channel without a manual upload.

**Apps:** Google Drive, YouTube

**Based on:** [Upload new Google Drive videos to YouTube with titles and descriptions](https://zapier.com/templates/details/6f4989c37b156aa98531ae4b800099cf1f0e5d470c7d4a6a829c15767d1c61e5) on zapier.com

## Install

This folder is a Zap template. Paste this into your AI agent:

> Build me this Zap, read how here: https://github.com/zapier/awesome-zaps/tree/main/zaps/upload-new-google-drive-videos-to-youtube

The agent follows `SKILL.md`: it asks you which Drive account and YouTube channel to use, then builds, tests and turns on the Zap in your account.

## Files

- `SKILL.md`: what the agent asks, builds and tests
- `workflow.ts`: the Zap's code
- `config.ts`: its settings, including the upload privacy and default description
- `connections/`: the accounts it uses (`google-drive`, `youtube`)
- `triggers/`: what starts it
